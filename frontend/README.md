Frontend — Transmar Recruitment (skeleton)

This directory is a placeholder for the Angular frontend. To create a starter Angular app:

1. Install Angular CLI globally (if not installed):
   npm install -g @angular/cli

2. Create the project in this directory (from repository root):
   npx @angular/cli new frontend --directory frontend --routing --style=scss

3. Implement modules: auth, products, assembly-lines, workstations, allocations.

This skeleton intentionally does not include a full Angular project. If you want, I can generate a minimal Angular app structure inside `frontend/`.
